# SolarSystem

## Descrição
    Software de gestão de monitoramento de usinas fotovoltaicas desenvolvido pelos programadores Atos Marques, Eduardo Jardim e Matheus Bryan.

## Objetivo
    O sistema possui a intenção de unificar plataformas de monitoramento fotovoltaico para que técnicos ou gestores tenham maior proatividade e para suas respectivas máquinas tenham menos consumo no processamento
