# SolarSystem

## Descrição
    Software de gestão de monitoramento de usinas fotovoltaicas desenvolvido pelos programadores Atos Marques, Eduardo Jardim e Matheus Bryan.

## Objetivo
    O sistema possui a intenção de unificar plataformas de monitoramento fotovoltaico para que técnicos da área ou gestores tenham maior proatividade, menor consumo de processamento de máquina, diminuição de erros... (Por enquanto, eu deixo dessa maneira) Atos e Edu, se conseguirem discorrer algo melhor, fiquem à vontade.
