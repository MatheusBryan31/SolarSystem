# Sistema de Monitoramento de Usinas Fotovoltaicas

## Usuários do sistema
    - Administrador;
    - Técnico

---
## Requisitos

### Requisitos Funcionais
    - RF01 - Cadastro de planta;
    - RF02 - Visualização de plantas;
    - RF03  - Edição de plantas;
    - RF04  - Remoção de plantas;

---

### Requisitos Não Funcionais
    - RNF01 - Atualização dos dados a cada um minuto;
    - RNF02 - Responsividade;
    - RNF03 - Feedback visuais;

## Regra de Negócio
    - RN01 - As plantas cadastradas devem possuir os mesmos dados informados na planta da plataforma da frabricante;
    - RN02 - Um inversor só pode ser inserido em uma planta;
    - RN03 - Apenas administradores podem excluir perfil dos técnicos;
