# Sistema de Monitoramento de Usinas Fotovoltaicas

## Usuários do sistema
    - Administrador;
    - Técnico

---
## Requisitos

# Requisitos Funcionais
    - Cadastro de planta;
    - Visualização de plantas;
    - Edição de plantas;
    - Remoção de plantas;

---

# Requisitos Não Funcionais
    - Atualização dos dados a cada um minuto;
    - Responsividade;
    - Feedback visuais;
